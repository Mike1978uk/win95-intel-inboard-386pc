# LE/PE locked-object census, 2026-11-14

Tool: `tools/le_census.py FILE...` (stdlib; LE/LX objects and PE sections).
A locked (PRELOAD, non-discardable) LE object costs whole 4 KB pages, so
"over-by" bytes past a page boundary cost a full page. Run on `drivers/`,
`dist/`, `vxd-patches/`, `custom_vkd/`, `ivt68fix/` and the card (`D:\`).

Rows are locked objects only (LE: PRELOAD and not DISC; PE: everything not
discardable, as one packed image). Discardable and pageable objects are
omitted. Files are deduplicated by md5. Ranked by pages freed by a trim of
<= 256 bytes, then by total locked pages. Unshipped variants with nothing
within 512 bytes of a boundary (imation LS-120 experiments, 36 files) are
not listed.

Next nearest: VDMAD_INBOARD obj 1 356 over (3 pages) and VPICD_INBOARD
obj 2 351 over (1 page); both Microsoft code.

PE (MPD) images are packed at SectionAlignment (0x200 for XTIDEMP, 0x10
for T130), not a page per section, so the locked cost is the extent of
the non-discardable sections:

- dist LS120STB.MPD (retired stub, not on card): 4,160 B = 2 pages, 64 over; 4 KB if the image is charged as packed.
- Card XTIDEMP.MPD: 9,280 B = 3 pages, 1,088 over. Not within 512.
- XTIDEMP experiment builds (control, fast, wordxfer, unpinned):
  8,768-8,776 B, 576-584 over. Not within 512, close.
- Card T130.MPD: 9,030 B = 3 pages, 838 over.
- Whether IOS charges INIT, .reloc or .rsrc (T130) against the locked
  image is not known; the extent above excludes them.

Init-time code in a resident object: none found. Every
`drivers/*/build/*.map` (swapcomp, shadowram, nmiwatch, m8feed) puts init
code in `_ITEXT`/`_IDATA` (discardable), not `_LTEXT`/`_LDATA`. `SWAPZF`
`_LDATA` is 14,959 of the 16,416 bytes; what it holds was not examined.

  files db88f64d, 4fafb2e9).
- `D:\WINDOWS\UMAXIS11.386` (third party, in SYSTEM.INI): obj 1 is 9,149 B,
  957 over. Not ours.
- Locked page counts on the running system were not read; sizes are from
  file headers. Per-object VMM overhead and PE section merging were not
  measured.
- Pageable LE objects (no PRELOAD) are not counted as locked.
