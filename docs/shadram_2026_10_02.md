# SHADRAM - the Inboard's idle 64 KB, given to Windows (bed, 2026-10-02)

Stage 3b of the RAM track. Driver: `drivers/shadowram/` (`SHADRAM.VXD`, 9,374 bytes, md5
`b4a4cd12`). Raw files: `docs/captures/2026-10-02_shadram_bed/`.

## What it does

The Inboard reserves 128 KB of its RAM as two shadow windows: `0x5F0000` (system BIOS copy)
and `0x5E0000` (EGA ROM copy). With `EGACACHE` off the EGA half is unused, and Windows never
sees it because it lies above the RAM `INBRDPC.SYS` reports. At `Sys_Critical_Init` the driver:

1. refuses if Windows already owns any of pages `5E0h`-`5EFh` (`_GetPhysPageInfo`);
2. maps the window and the `F0000` and `C0000` ROM areas (`_MapPhysToLinear`);
3. per page: saves it, writes `55AA55AAh` and `AA55AA55h`, checks each reads back and does
   not appear at the same offset in either ROM area (which would mean the window aliases live
   shadow), restores it;
4. writes each passing page's physical address into every dword and checks none was
   overwritten (two pages decoding to the same RAM);
5. hands each survivor to the VMM with `_AddFreePhysPage` - init-time only, per the DDK
   (`DOCS/KERNEL/KERNEL.DOC`), and why the work is at `Sys_Critical_Init`.

Counters at `Device_Init`: `SHADRAM\PagesTested`, `PagesAdded`, `PagesFailed`, `Status`
(0 ok, 1 already owned, 2 window not mappable, 3 ROM areas not mappable).

## Bed result

Same bed and config as the SWAPCOMP A arm (`vm_magnaram_off` master, 86Box `40466b22f`),
SWAPCOMP off, `device=C:\SHADRAM.VXD` the only change. Workload `PAGERUN S`.

The donated pages were in use: the free pool is empty for the whole workload (`cpgFree` ~0),
and the run completed. **One run per arm**: the paging cut is far larger than the ~1% per
64 KB the layout doc estimated, so it needs repeating before it is quoted.

## On the 5160

The address comes from the emulator model and UniPCemu, not the card. The checks turn a wrong
window into lost pages, not a crash, except one case they cannot see: the window aliasing
live RAM other than the two ROM areas. So: image the CF, `EGACACHE` off (it uses this half),
one boot with PERFLOG, read `SHADRAM\*`. Then an A/B like SWAPCOMP's.
