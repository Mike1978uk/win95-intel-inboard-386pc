# L6: the whole card for 3D (2026-11-19)

Owner, 11-19: "we need to make use of the unused silicon ... the more work the card does the less time on the bus,
the less cpu cycles". Worklist L6. Cost unit: one port write, ~7.6 us on the 5160.

## (a) Census: writes for one triangle by polygon fill (`tools/dos3d/m8dos.c` `batch_flush`)

| Job | Writes | Notes |
|---|---|---|
| Outline into the scratch plane | 16 | `WRT_MASK` + 5 an edge (`LINEDRAW_INDEX` + 4 coordinates), each edge sent top to bottom on its own |
| Fill blit from the scratch plane | 11 | `DESTX_DIASTP`, `DESTY_AXSTP`, `SRC_X_START` are the same for every polygon |
| Outline again on the visible page | 9-10 | colour (if changed), `LINEDRAW_INDEX`, 2 a corner + the closing corner |
| Batch set-up, restore, scratch clear (shared by up to 8) | ~2.5 | |
| Total | ~40 | card bench: 2,002 writes a frame for 50 triangles + clear (`captures/2026-11-19_c3_card/`) |

Polygon cost does not depend on its size: the engine fills the pixels. The edges are not the main cost.

## Probes, in order (bed first: the bed equals the card on CMD fills; card for timing)

| # | Question | If yes | Saves a triangle |
|---|---|---|---|
| P1 | Do `DESTX_DIASTP`, `DESTY_AXSTP`, `SRC_X_START` keep their values across fill commands? | write them once a batch (a register shadow) | 3 |
| P2 | Does `LINEDRAW_POLY` mode accept a connected outline (index once, 2 writes a corner) with edges in any direction, and fill the same? | outline in one run | ~6 |
| P3 | Can the fill include the boundary pixels, so the second outline goes? | drop the visible outline | ~9 |
| P4 | Hardware depth test: pixel = depth x 16 + colour, `COLOR_CMP` = polygon depth, `DEST_CMP_FN` "keep if dest <" (measured 10-10 on CMD fills, both operands WRT_MASK-masked) | per-pixel occlusion with no CPU sort; palette gives depth fog | -1 (adds one); gains correctness |

P1-P3 together: ~40 -> ~21-25 writes a triangle, close to twice the triangles a second. P4 trades colours (16, or
32 with 8 depth levels) for correct overlaps. Then (c)-(g) of L6.
