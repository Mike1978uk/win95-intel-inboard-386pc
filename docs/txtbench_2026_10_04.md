# TXTBENCH on the 5160 - text costs ~81 us per character (#41)

`tools/txtbench/TXTBENCH.EXE`, one run, 800x600x8, Small Fonts (dpi 96), ATI Mach8 (`ATIM8.DRV`):

| test | ms | per unit |
|---|---|---|
| text, system font, mixed | 5,133 | ~81 us per character (63,000) |
| text, system font, all `m` | 6,496 | ~103 us per character |
| text, fixed font | 5,578 | ~89 us per character |
| blit 300x200, x100 | 368 | ~16 MB/s on the card |
| fill 600x400, x100 | 770 | ~31 MB/s on the card |

Blits and fills run on the card. Text costs about 20 port accesses per character (3.8 us each), and the
wider glyph costs more: the glyph's pixels cross the bus every time, so `ATIM8.DRV` does not cache
glyphs on the card. A full 800x600 screen of text (~3,700 characters) takes ~0.3 s. Small Fonts were
already set, so no settings lever is left; a glyph cache would mean reworking the 16-bit driver.

The 86Box bed cannot measure this: its Windows falls back to VGA (the emulated 8514 side never switches on).
