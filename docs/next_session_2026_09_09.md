## 1. State: the transport works

Verified on the real 5160, 2026-09-08, over COMrade:

```
ATA status   (0x18+7) = 0x50   DRDY | DSC     <- a ready drive
ATA drv/head (0x18+6) = 0xA0   master select
```

The recipe, all four steps confirmed:

1. **CONNECT** `CPP(0xE0)` — data port gets `22 AA 55 00 FF 87 78 E0` (each byte twice, I/O delay
   between groups), then control pulsed `0x04` → `0x05` → `0x04`, then `FF FF` to the data port.
2. **ADDRESS** by offset map — internal bridge `0x00`, IDE control `0x10`, **IDE task file `0x18`**.
   ATA status is `0x18+7 = 0x1F`.
3. **READ** with the NIBBLE handler (`0x3A1B`) — two status reads, `(second & 0xF0) | (first >> 4)`.
4. **DISCONNECT** `CPP(0x30)`.

Corroborated independently by Linux `epat.c`, which gives the identical CPP sequence and the same
offset map. Read as reference only; no code taken. **Repo stays MIT.**

## 2. Architecture to build

**Nibble for the task file, ECP `rep insb`/`rep outsb` for sector data.**

Registers are a few bytes per command, so nibble costs nothing and works on any SPP port. All the
throughput is in the data phase, which uses the ECP FIFO at `base+0x400` with the hardware doing the
handshake (`0x4465` read, `0x4BD3` write in `SD120PPD.SYS`), after setting control bit 5 for reverse.

That keeps a portable SPP-only fallback in the same binary for machines without an ECP card.

⚠ **Never copy the vendor's DMA-assisted block path.** It writes `out 23h,al` / `out 22h,al`, and on
this XT those **alias onto the 8259** — the issue #22 keyboard-killer, in the *transfer* path rather
than the `/ni`-skippable init. `dmaEn` stays **0** regardless (technique 62: 20-bit DMA reach).

## 3. Order of work

1. **Open `SD120PPD.MPD`** — the vendor's own Win95 miniport, 79,872 bytes, sitting in
   `drivers/imation_ls120/` and **never disassembled**. It is a second implementation of everything
   above *plus* the ATAPI command layer and the SCSIPORT plumbing we are about to write. It is a PE,
   i386, so it disassembles cleanly. **Do this before writing any code** — technique 107.
2. **ATAPI command layer** — task-file setup, `PACKET` (`0xA0`), status polling, data phase. Standard
   once register access works, and the `.MPD` should show it directly.
3. **Miniport shell** — `XTIDEMP.MPD` is the working template for SCSIPORT registration, `Polling=1`
   and `AdapterSettings`. Take `PORT=0x378` from `AdapterSettings`, not from the device node
   (technique 97 — that fight cost four sessions on #21).
4. **Test in emulation if possible.** There is currently no EPAT bridge model in 86Box, so every
   iteration costs real hardware. A minimal bridge stub answering the CPP checkpoints would remove
   that permanently — worth considering before a long build-test loop.
