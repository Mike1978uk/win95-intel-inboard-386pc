# DMAINV on the 5160, 2026-09-30

Raw: `docs/captures/dmainv_5160_2026-09-30.txt`. Real DOS, "Command prompt only".

- **Channel 0 (refresh) is running.** Address `53E7` then `5505`, count `AB34` then `A92C`
  between two reads.
- **Channels 1-3: address and count all `0000`.** Nothing programmed them this boot.
- **Status `91h`:** channel-0 terminal count and request, and a **channel-3 request (bit 7)**,
  as on 09-20 (`81h`). The parallel card is jumpered to DMA 3, so it is the likely driver of
  DREQ3; moving its jumper and re-reading would prove it.
- **PIT channel 1:** 32 samples from 2 to 17. It counts 18..1, so the divisor is the BIOS
  default **18**: one refresh every 15.1 us (#33 step 1).
